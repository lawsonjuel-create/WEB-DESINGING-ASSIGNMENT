# StayEasy SL — VS Code Website Project

A responsive front-end website based on the DCOM 204 Web Design assignment: **StayEasy SL – Student Accommodation Finder**.

## Files
- `index.html` — page structure and sample accommodation listings
- `style.css` — layout, colours, typography and mobile responsiveness
- `script.js` — search, filters, save buttons, room details modal and demo contact form

## Run in Visual Studio Code
1. Open Visual Studio Code.
2. Select **File → Open Folder** and choose `StayEasy_SL_VSCode`.
3. Open `index.html`.
4. If you have the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**. Otherwise, open `index.html` in a browser.

## About the pictures and listings
The website uses real photographic images hosted by Unsplash. An internet connection is required for those images to load. The room listings, prices and facilities are sample/demo content for the assignment; they are not verified live vacancies.

## Important
This is a front-end project only. The search and filters work on the sample listings, but there is no database, login, payment system, owner dashboard or message server yet.
